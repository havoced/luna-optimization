# 🌙 Luna Optimization

**Luna Optimization** — приложение для Windows 10/11, объединяющее оптимизацию системы, игровые настройки, управление оборудованием и дополнительные инструменты в одном интерфейсе.

Luna создана для пользователей, которым нужен контроль над производительностью компьютера без постоянной работы с реестром, службами Windows, PowerShell и сторонними утилитами.

**Платформа:** Windows 10/11 x64  
**Текущая ветка:** 3.1.28  
**Формат:** Desktop / Portable  
**Языки:** Русский, English

[Официальный сайт](https://lunaoptimization.pages.dev/) · [GitHub Releases](https://github.com/havoced/luna-optimization/releases)

## 💎 Luna Free и Luna Pro

**Luna Free**

Бесплатная версия включает основной каталог оптимизации, пресеты, инструменты Windows, управление подключениями, друзей, профили и другие базовые возможности.

**Luna Pro**

Расширенная версия предоставляет дополнительные игровые настройки, эксклюзивные темы, оформление профиля и расширенные возможности управления производительностью.

Подписка доступна на 30 дней, 90 дней или бессрочно.

## ❌ Чего нет в Luna

Мы предпочитаем честно описывать возможности приложения.

- **Нет гарантированного повышения FPS.** Результат зависит от оборудования, игры и состояния Windows.
- **Нет встроенного полноценного VPN.** Flowseal не меняет публичный IP-адрес и географическое расположение.
- **Нет гарантированного обхода любых блокировок.** Работа зависит от провайдера и конкретного подключения.
- **Нет поддержки macOS и Linux.** Luna разработана для Windows.
- **Нет универсального установщика всех драйверов.** Расширенный мастер установки ориентирован на NVIDIA.
- **Нет SnapTap для CS2.** Использование этой функции в CS2 намеренно ограничено.
- **Нет встроенного обхода античитов.** Luna не предназначена для обхода защиты игр.
- **Нет автоматической оплаты LC банковской картой.** Пополнение пока осуществляется через Discord.
- **Нет гарантии, что каждый твик подходит любому ПК.** Перед применением необходимо учитывать рекомендации и предупреждения.

## 🛡️ Безопасность и контроль

Luna не применяет выбранные системные изменения без подтверждения пользователя.

Для поддерживаемых настроек предусмотрено восстановление предыдущего состояния. Перед серьёзной оптимизацией рекомендуется создать точку восстановления Windows.

Некоторые операции требуют прав администратора и перезагрузки компьютера.

Приложение не заменяет антивирус, резервное копирование и стандартные механизмы восстановления Windows.

## 📥 Установка

1. Перейдите в [GitHub Releases](https://github.com/havoced/luna-optimization/releases).
2. Скачайте последнюю опубликованную версию Luna Optimization.
3. Запустите Portable EXE.
4. При необходимости предоставьте права администратора.
5. Войдите в аккаунт или создайте новый.
6. Выберите необходимые инструменты оптимизации.

Для аккаунтов, магазина, социальных функций и синхронизации необходим интернет. Некоторые системные инструменты могут работать локально.
