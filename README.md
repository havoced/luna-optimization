# PCBoost 0.2.0

Electron-приложение для мониторинга и оптимизации Windows.

## Запуск

```bash
npm install
npm start          # терминал ОБЯЗАТЕЛЬНО от имени администратора
npm run build      # сборка .exe в dist/
npm run release    # сборка + публикация релиза на GitHub (см. раздел "Автообновление")
```

Внешних npm-зависимостей нет — только Electron. Автообновление реализовано
своим кодом (`core/portable-updater.js`), без `electron-updater`.

## Что изменилось в этой версии

### Производительность: почему было 100% CPU и 50 процессов

Старый `main.js` раз в секунду вызывал `si.graphics()` и `si.cpuTemperature()`.
На Windows эти функции внутри запускают WMIC/PowerShell — то есть **каждую секунду
рождался новый процесс**. Плюс каждый `reg`/`sc` при твиках — ещё по процессу.

Что сделано:

| Было | Стало |
|---|---|
| `si.currentLoad()` + `si.mem()` каждую секунду | расчёт из `os.cpus()` / `os.totalmem()` — **ноль процессов** |
| `si.graphics()` и `si.cpuTemperature()` каждые 4 сек | **один вечно живущий** PowerShell, который сам печатает JSON раз в 3 сек |
| модель CPU/GPU перечитывалась постоянно | читается **один раз** при старте |
| опрос шёл даже в свёрнутом окне | опрос останавливается при сворачивании |
| повторный запуск ярлыка = новый набор процессов | `requestSingleInstanceLock()` — второй запуск разворачивает существующее окно |
| каждая reg-команда = отдельный `cmd.exe` | `execBatch()` склеивает до 25 команд в один вызов |
| — | выключены лишние подсистемы Chromium (окклюзия, media keys, фоновая сеть) |
| — | в Настройках можно выключить аппаратное ускорение — минус ещё один процесс |

Отдельный твик **«Объединить процессы svchost»** чинит уже саму Windows: по
умолчанию каждая служба живёт в своём `svchost.exe`, отсюда десятки строк в
диспетчере задач.

### Вкладки

- **Драйвера — удалена.**
- **Система** — паспорт ПК: Windows, CPU, материнка, BIOS, видеокарты с версиями
  драйверов, планки ОЗУ по слотам, накопители + живая загрузка по каждому ядру.
- **Твики** — 60+ твиков, поиск, 6 пресетов (Valorant, Dota 2, CS2, GTA 5,
  Стриминг, Офисный ПК).
- **Твики GPU** — новая вкладка с тремя разделами: Общие / NVIDIA / AMD.
  Приложение само определяет, какая карта стоит, и предупреждает, если выбран
  чужой вендор.
- **Службы** — живой список всех служб с пуском/остановкой/сменой типа запуска.
  Критические (звук, DHCP, RPC, Defender, брандмауэр) физически заблокированы от
  отключения.
- **Очистка** — сначала сканирование с реальными размерами по 13 категориям
  (Temp, Prefetch, кэш обновлений, кэши шейдеров DirectX/NVIDIA/AMD, кэш браузеров,
  корзина, Windows.old), потом удаление только отмеченного.
- **Сеть** — теперь открывается: адаптеры, IP/шлюз/DNS, текущие параметры TCP,
  пинг-тест с джиттером по 4 целям, переключение DNS (Cloudflare / Google /
  Quad9 / AdGuard / авто), сброс сетевого стека и 11 сетевых твиков.
- **Настройки** — переключатели анимаций, аппаратного ускорения, паузы опроса и
  частоты обновления + кнопка **«Вернуть всё как было»** со списком всех
  сохранённых состояний и датами.

### Анимация

Страницы лежат стопкой и переключаются через `opacity` + `translate3d` на GPU-слое
(260 мс, easing `cubic-bezier(.22,.61,.36,1)`). Направление зависит от того, вверх
или вниз по сайдбару ты идёшь. Отключается тумблером в Настройках и уважает
системную настройку «уменьшить движение».

## Новые твики

**GPU — общие:** отключение MPO (лечит мерцание и фризы в Win11), TdrDelay 10 сек
(меньше вылетов «драйвер перестал отвечать»), приоритет GPU для игр через MMCSS,
отключение fullscreen-оптимизаций, включение VRR, перевод видеокарты в режим MSI.

**NVIDIA:** PowerMizer на максимум, отключение HDCP, отключение preemption,
телеметрия (реестр + задачи планировщика + служба), кэш шейдеров до 10 ГБ.

**AMD:** отключение ULPS, снятие программного термотроттлинга, отключение power
gating блоков (UVD/SAMU/VCE), StutterMode, compute preemption, телеметрия
AMD User Experience, кэш шейдеров.

**Система:** объединение svchost, Win32PrioritySeparation, задержка автозагрузки,
визуальные эффекты, реклама Windows, фоновые UWP-приложения, виджеты, веб-поиск
Bing, отчёты об ошибках, удалённый помощник, игровой режим, ускорение Проводника,
NTFS last-access, Fast Startup, сжатие памяти, задачи телеметрии, TRIM.

**Ввод:** эталонная чувствительность мыши 6/11, скорость автоповтора клавиатуры,
отключение залипания клавиш.

**Питание:** запрет парковки ядер, отключение ASPM у PCIe, диски не засыпают.

**Сеть:** настройка TCP-стека (autotuning, CTCP, heuristics, RSC/RSS, ECN),
параметры реестра TCP (MaxUserPort, TcpTimedWaitDelay, TTL), возврат 20% QoS,
оффлоады сетевой карты (LSO, Interrupt Moderation, EEE), отключение NetBIOS,
IRPStackSize, кэш DNS, запрет раздачи обновлений другим ПК.

**Службы:** добавлены Delivery Optimization, WerSvc, PcaSvc, RemoteRegistry,
геолокация, смарт-карты, родительский контроль, WAP Push, Кошелёк, телефония,
сенсорный ввод, биометрия.

## Откат

Перед каждым твиком текущее значение пишется в `%APPDATA%/pcboost/pcboost-backup.json`.
Кнопка «Вернуть всё как было» (Настройки или Главная) возвращает каждое значение
ровно туда, где оно было — включая случай, когда значения раньше не существовало
(тогда оно удаляется).

Единственное необратимое — удалённые во вкладке «Очистка» файлы.

## Чего здесь сознательно нет

Отключения Defender и Windows Update. Прирост FPS от этого около нуля, а система
остаётся без патчей. Вместо этого — исключение папок игр из проверки и штатная
пауза обновлений на 7 дней.

## Права администратора

`reg`, `sc`, `netsh`, `powercfg` и управление адаптерами без прав админа вернут
ошибку доступа. При `npm start` запускай терминал от администратора; в собранном
.exe UAC запросится сам (`requestedExecutionLevel: requireAdministrator`).

## 0.3.0 — Luna Optimization

Приложение переименовано в **Luna Optimization**. Слоган в шапке — «Бесплатно
делаю людей счастливее.»

### Кодировка (были «?????» в Службах и Системе)

PowerShell по умолчанию пишет в stdout в кодовой странице консоли (`cp866` на
русской Windows) — кириллица из WMI превращалась в вопросительные знаки ещё до
Node. Теперь каждый PowerShell-скрипт форсирует `UTF8Encoding` на выходе
(`core/ps-runner.js`, `core/monitor.js`), а Node читает stdout явно как `utf8`.

### Тяжёлая артиллерия (`tweaks/boost-tweaks.js`)

Новая группа твиков с самым заметным измеримым эффектом — скрыта по умолчанию
за переключателем «Показывать тяжёлую артиллерию» на странице Настройки, не
входит в кнопку «Оптимизировать» на Главной, применяется только вручную:

- **Вернуть точный системный таймер** — Windows 11 тихо сломала
  `timeBeginPeriod(1)` ради энергосбережения ноутбуков; `GlobalTimerResolutionRequests`
  официальный обходной путь (задокументирован Bruce Dawson / Microsoft).
- **Отключить VBS/Memory Integrity** — 5–15% FPS в CPU-зависимых играх ценой
  защиты ядра от уязвимых драйверов. Честно помечен `caution`.
- **Отключить Power Throttling** — Windows душит частоты «неактивным» окнам.
- **Ядро и драйверы всегда в ОЗУ** (`DisablePagingExecutive`) — от 16 ГБ.
- **Отключить Prefetcher/Superfetch в реестре** — для SSD/NVMe.
- **HPET/dynamic tick через bcdedit** — снижает DPC latency на AMD-платформах.
- **Запретить простой CPU** (C-states) — цена: температура и энергопотребление.
- **MSI-режим для USB/NVMe/сети/звука** — не только GPU, как раньше.
- **Запретить отключение USB для энергосбережения.**
- **Отключить NDU** (драйвер учёта трафика, известная утечка памяти).
- **Полностью вырубить Xbox Game Bar** (не только фоновую запись).
- **Отключить Storage Sense.**
- **Отключить гибернацию** — освобождает `hiberfil.sys` (~40% от ОЗУ).
- **Классическое контекстное меню Win11** — без лишнего клика и паузы.
- **Точка восстановления одним нажатием** — подстраховка перед агрессивными
  твиками.

### Вкладка «Дизайн»

5 готовых тем (Тёмная, Чёрно-красная, Светлая, Графит, Полночь), 6 акцентных
цветов поверх любой темы и переключатель плотности интерфейса (Просторно /
Компактно). Всё применяется мгновенно через `data-theme`/`data-accent`/
`data-density` на `<html>` и сохраняется в `pcboost-settings.json`.

## 0.4.0 — автообновление, окно загрузки, пересобранные пресеты

### Автообновление в portable-сборке

Сборка собирается только как `portable` (`win.target: "portable"`) — без
инсталлятора, готовый `.exe`. У `electron-updater`/`autoUpdater` автообновление
из коробки работает **только для NSIS-инсталляции** (ему нужен файл
`app-update.yml`, который electron-builder кладёт в `resources` исключительно
при сборке NSIS-таргета). Для portable этот файл не создаётся в принципе —
поэтому обычный `autoUpdater.checkForUpdates()` падает с
`ENOENT: ...resources\app-update.yml` при любой конфигурации. Это официально
не поддерживаемый сценарий, а не баг настройки (см. electron.build/auto-update:
поддерживаемые Windows-таргеты — только NSIS).

Поэтому автообновление реализовано своим модулем — `core/portable-updater.js`,
без зависимости от `electron-updater`:

1. При проверке тянет `GET https://api.github.com/repos/<owner>/<repo>/releases/latest`
   (owner/repo — из `package.json` → `build.publish`) и сравнивает `tag_name`
   с `app.getVersion()`.
2. Если вышла версия новее — качает `.exe`-ассет релиза (ищет по имени
   `*portable*.exe`, см. `build.portable.artifactName`) во временную папку и
   проверяет целостность (PE-заголовок `MZ` + совпадение размера с тем, что
   заявлен в релизе на GitHub).
3. По подтверждению пользователя (`quitAndInstall`) пишет маленький `.bat` во
   временную папку, который: ждёт, пока наше приложение закроется и отпустит
   файл (Windows не даёт перезаписать exe запущенного процесса), переносит
   новый файл поверх реального portable-exe (путь берётся из
   `process.env.PORTABLE_EXECUTABLE_FILE` — его выставляет сам
   portable-лаунчер electron-builder перед стартом), перезапускает приложение
   и удаляет себя.

Перед сборкой релиза замени `owner`/`repo` в `package.json` (`build.publish`)
на свой GitHub-аккаунт и репозиторий, затем:

```bash
npm run release     # electron-builder --win --publish always
```

Это соберёт `Luna Optimization-<version>-portable.exe` и опубликует его как
GitHub Release (нужен `GH_TOKEN` в переменных окружения — токен с правом
`repo`). Каждый следующий `npm run release` с увеличенной `version` в
`package.json` подхватится у уже скачавших приложение пользователей.

Поведение в приложении:
- При запуске (в собранном `.exe`, не в `npm start`) тихо проверяет GitHub, если
  включена настройка «Проверять обновления автоматически» (по умолчанию включена).
- Прогресс скачивания показывается на окне загрузки при старте.
- Когда обновление скачано — модальное окно с подтверждением установки, ничего
  не ставится без явного согласия.
- На странице «Настройки» есть кнопка «Проверить обновления» для ручной проверки
  в любой момент, и текущая версия приложения.
- Если приложение запущено не из portable-обёртки (например, `npm start` в
  разработке — там нет `PORTABLE_EXECUTABLE_FILE`), самоподмена файла
  невозможна: статус покажет ссылку на релиз для ручного скачивания вместо
  ошибки.

Важные оговорки для продакшена:
- Файл не подписан код-сертификатом — Windows SmartScreen и часть антивирусов
  будут ругаться на скачанный portable `.exe` (это уже было верно и до этого
  изменения, просто раньше до скачивания дело не доходило). Если бюджет
  позволяет — code signing сильно снижает ложные срабатывания.
- Самоподмена запущенного exe через отсоединённый `.bat` — стандартный трюк для
  portable-приложений, но эвристики некоторых антивирусов иногда настороженно
  относятся к «exe, который сам себя перезаписывает». Стоит прогнать собранный
  `.exe` через VirusTotal перед релизом.
- GitHub API отдаёт 60 запросов/час на анонимный IP — для одной проверки на
  старте приложения этого с большим запасом достаточно.

### Окно загрузки с процентами

показывается сразу при старте и идёт по шагам (ядро приложения → железо →
проверка обновлений) с процентом и подписью, затем закрывается и показывается
основное окно.

### Пресеты твиков

  и «Тихий офисный ПК» убраны.
- Пресет GTA5RP больше не трогает SysMain, DiagTrack и подобные службы — они
